Evaluating LLM Products

A deep workshop on judging language-model features: building test sets, reviewing outputs and tracking quality over time.

Syllabus

  1. Day 1
    Defining good outputTurning vague quality into written criteria.
  2. Day 1
    Building test setsRepresentative cases, edge cases and failure cases.
  3. Day 2
    Automated and human reviewWhere each is reliable and where it is not.
  4. Day 3
    Tracking qualityRegressions, releases and model changes.

Hands-on project

Build a first evaluation set and scorecard for an LLM feature you own.

You will be able to

  • Write quality criteria for model output
  • Build and maintain an evaluation set
  • Make release decisions from evaluation evidence
