Using AI to challenge a product spec

AI is useful as a skeptical reader. Give it your spec and ask it to find what an engineer, a designer and a support agent would ask. You still decide what matters.

spec-critique.prompt
role:   senior engineer reviewing a spec
input:  <paste the spec>
task:   list unclear requirements, missing edge cases
        and questions engineering will ask
format: table of requirement | gap | question
rule:   quote the spec line for every item

How to use the result

  • Keep only the gaps that are real for your product
  • Answer each question in the spec itself
  • Run it again after you revise, and compare
The rule that mattersAsk for a quote from the spec for every point. Items without a quote are the model guessing.
